# ✅ To Do App

A clean and functional **Task Manager App** built with HTML, CSS, and JavaScript.
Manage your daily tasks with ease — add, complete, edit, delete, and filter them!

## 📁 Project Structure

```
todo-app/
├── index.html       ← Main HTML structure
├── style.css        ← All styling
├── JavaScript.js    ← App logic & functionality
└── README.md        ← Project documentation
```

---

## ✨ Features

- ➕ Add new tasks instantly
- ✅ Mark tasks as completed (strikethrough effect)
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🔍 Filter tasks — View All / Completed / Pending
- ⚠️ Error message for empty task input
- 📱 Responsive design for mobile & desktop

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure |
| CSS3 | Styling & responsive layout |
| JavaScript | App logic & DOM manipulation |
| Bootstrap 5 | UI components & buttons |
| Font Awesome 6 | Icons (edit, delete) |
| Google Fonts | Bebas Neue & Poppins typography |

## 📐 Responsive Breakpoints

| Breakpoint | Behavior |
|---|---|

## 🎨 Design

**Color Palette:**
- Background: Dark gradient `#1b1d1d → #000000`
- Container: Light purple gradient `#cbc4ec → #dbddeb`
- Title: Gradient `#f1f1f3 → #0d0e13`
- Task Cards: White with dark left border
- Error: `#dc3545` (Bootstrap red)

**Typography:**
- Title → `Bebas Neue`
- Body → `Segoe UI / Poppins`

---

## 🚀 How to Run

1. Download or clone the repository
2. Make sure all 3 files are in the same folder:
   - `index.html`
   - `style.css`
   - `JavaScript.js`
3. Open `index.html` in any browser
4. Start adding your tasks! ✅
